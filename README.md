# MukuroIkusaba-Danganronpa-But-HitmanAbsolution
Replaces Agent 47 with Mukuro Ikusaba in Hitman: Absolution. Includes adapted animations and a Windows installer with a compatibility check./// Vibecode
A Windows mod that replaces Agent 47 with Mukuro Ikusaba. Includes adjusted animations and the 0.38 FPS optimizations.

[Download from Releases](../../releases/latest)

1. Extract the entire release ZIP and close the game.
2. If you already installed a previous version with this installer, run UNINSTALL.cmd first.
3. Disable the Steam Overlay for Hitman: Absolution.
4. Run INSTALL.cmd and select the game's HMA.exe. Launch the game through Steam.

CHECK.cmd checks your game build without installing the mod. Compatibility depends on the engine build. If the check fails, attach MukuroCompatibilityReport.json when reporting the issue.

To uninstall, close the game and run UNINSTALL.cmd. It restores the files backed up during installation.
